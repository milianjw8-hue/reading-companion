📋 Blogger 발행용

아래 버튼을 누르면 본문 HTML이 클립보드에 복사됩니다. Blogger 글쓰기 화면에서 HTML 보기로 전환한 뒤 붙여넣으세요.

영어 논문을 읽다 보면 흐름이 끊기는 순간이 있습니다. 모르는 표현 하나 때문에 번역기 탭으로 넘어가고, 돌아오면 어디까지 읽었는지 놓칩니다. Figure는 더 심합니다. 축이 뭘 뜻하는지 알려면 본문을 뒤져야 하는데, 그 사이 논지를 잃어버립니다.

그래서 PDF를 읽으면서 그 자리에서 물어볼 수 있는 도구를 만들었습니다. 설치가 없고, 서버가 없고, HTML 파일 하나로 동작합니다. 비용도 들지 않습니다.

무엇을 하는 도구인가

PDF를 열고 읽다가 모르는 문장을 드래그로 선택하면 번역·설명·단어풀이 버튼이 뜹니다. 그림이나 표는 영역을 잘라내서 물어볼 수 있습니다.

핵심은 그림만 보내지 않는다는 점입니다. 잘라낸 이미지와 함께 그 페이지의 본문 전체가 전달됩니다. 그래서 캡션과 본문 서술을 근거로 그림을 읽습니다. "Fig. 3의 이 패널이 왜 이런 모양인가"를 물으면 본문의 해당 문단을 짚어 답합니다.

항목내용
설치없음. HTML 파일 더블클릭
서버없음. 브라우저 안에서만 처리
비용무료 한도 내 0원

설치 — 5분이면 끝납니다

1단계. API 키 발급

aistudio.google.com/apikey 에 접속해 Google 계정으로 로그인합니다. API 키 만들기를 누르면 바로 발급됩니다. 신용카드는 필요 없습니다.

프로젝트가 없다면 "새 프로젝트 만들기"를 먼저 누르면 됩니다. 생성된 키를 복사해 두세요. AIza 로 시작하는 39자 문자열입니다.

2단계. 파일 내려받고 열기

배포 파일의 압축을 풀고 index.html 을 더블클릭합니다. 브라우저가 바로 열립니다. 화면 맨 위에 빨간 띠가 없으면 정상입니다.

3단계. 키 입력하고 모델 고르기

복사한 키를 붙여넣고 사용 가능한 모델 불러오기를 누릅니다. 목록이 뜨면 Flash 계열을 고르세요.

모델 ID를 직접 타이핑하지 마세요. 무료 모델명은 수시로 바뀌기 때문에, 목록에서 고르는 편이 확실합니다.

4단계. 저장 → 연결 테스트

저장을 누른 뒤 연결 테스트로 "연결 성공"을 확인합니다. 키는 브라우저에 남으므로 다음부터는 이 과정을 건너뜁니다.

5단계. PDF 열기

PDF 선택으로 논문을 엽니다. 페이지는 스크롤할 때마다 필요한 만큼만 그려지므로 수백 페이지짜리 원서도 무겁지 않습니다.

활용법

문장이 안 읽힐 때

본문에서 문장을 드래그하면 아래쪽에 검은 막대가 뜹니다. 네 가지 버튼이 있습니다.

  • 번역 — 자연스러운 한국어로
  • 쉽게 설명 — 문맥을 짚어 풀어서
  • 단어·표현 — 뜻, 품사, 이 문맥에서의 의미 순으로
  • 직접 질문 — 그 구절을 붙인 채 자유 질문

그림과 표가 안 읽힐 때

헤더의 🖼 버튼을 누르면 커서가 십자로 바뀝니다. 그림을 드래그로 감싸면 채팅창에 썸네일이 붙습니다. 그냥 보내면 "본문과 연결해 설명"이 기본 질문으로 나갑니다.

구체적으로 물으면 더 정확합니다. "y축 단위가 뭐야", "두 패널의 차이가 뭐야", "이 실선과 점선이 각각 뭘 나타내나" 같은 식입니다.

수식은 그림으로 잘라서 물어보세요 PDF의 수식은 텍스트로 추출할 때 깨지는 경우가 많습니다. 드래그 선택 대신 🖼 로 잘라서 이미지로 보내면 훨씬 정확하게 읽습니다.

자유 질문

아래 채팅창에 무엇이든 물어보면 됩니다. 질문을 보낼 때 현재 페이지 원문과 이전 페이지 끝부분이 자동으로 함께 전달되므로, "이 문단 논지가 뭐야" 같은 지시대명사 질문이 그대로 통합니다.

빠른 질문 버튼도 있습니다. 페이지 요약, 논지 정리, 용어 정리, 방법론 네 가지입니다. 처음 보는 논문을 훑을 때 유용합니다.

문맥은 페이지 단위입니다 3장의 Methods를 1장에서 물어보면 답하지 못합니다. 해당 페이지로 스크롤한 뒤 물어보세요. 헤더의 p.12 표시가 지금 어느 페이지 기준인지 알려줍니다.

한계도 분명합니다

  • 문서 전체 질문 불가 — 문맥이 페이지 단위입니다. 전체 요약이나 장 간 비교는 못 합니다
  • 스캔본 불가 — 이미지로만 된 PDF는 선택·질문이 안 됩니다
  • 2단 조판 주의 — 텍스트 추출 순서가 좌우 단을 넘나들며 섞일 수 있습니다. 이럴 땐 해당 문단을 직접 드래그하면 해결됩니다
  • 검증은 필수 — 언어모델은 틀립니다. 전문 용어와 수치는 원문과 대조하세요
