📖 Reading Companion

1. 이 도구가 하는 일

PDF를 열고 읽다가 모르는 문장을 드래그로 선택하면 번역·설명·단어풀이 버튼이 뜹니다. 그림이나 표는 영역을 잘라서 물어볼 수 있고, 이때 그림만 보내는 게 아니라 그 페이지 본문이 함께 전달되어 캡션과 본문 서술을 근거로 답합니다.

항목내용
설치없음. HTML 파일 하나를 브라우저로 열면 끝
서버없음. 모든 처리가 브라우저 안에서 일어남
비용Google AI Studio 무료 한도 내에서 0원
필요한 것Google 계정, 최신 브라우저(Chrome·Edge·Safari), 인터넷

2. 5분 안에 시작하기

1
API 키 발급 aistudio.google.com/apikey 에 접속해 Google 계정으로 로그인한 뒤 API 키 만들기를 누릅니다. 신용카드는 필요 없습니다. 생성된 키를 복사해 두세요.
2
앱 열기 index.html 을 더블클릭합니다. 브라우저가 바로 열립니다. 화면 맨 위에 빨간 띠가 없으면 정상입니다.
3
키 붙여넣고 모델 고르기 키를 입력한 뒤 사용 가능한 모델 불러오기를 누릅니다. 목록에서 Flash 계열을 고르세요. 모델 ID를 직접 타이핑하지 마세요 — 무료 모델명이 자주 바뀌기 때문에 목록에서 고르는 편이 안전합니다.
4
저장 → 연결 테스트 저장 후 연결 테스트를 눌러 "연결 성공"이 뜨는지 확인합니다. 키는 브라우저에 남아 다음에 다시 입력할 필요가 없습니다.
5
PDF 열기 PDF 선택으로 논문이나 원서를 엽니다. 페이지는 스크롤할 때마다 필요한 만큼만 그려집니다.
키를 바꾸거나 지우려면 화면 오른쪽 위 ⚙ 를 누르면 설정 화면으로 돌아갑니다. 키 삭제를 누르면 브라우저에서 완전히 지워집니다.

3. 읽으면서 물어보기

구절 선택

본문에서 문장을 드래그하면 아래쪽에 검은 막대가 뜹니다.

  • 번역 — 자연스러운 한국어로 옮깁니다
  • 쉽게 설명 — 문맥을 짚어 풀어 설명합니다
  • 단어·표현 — 어려운 단어를 뜻·품사·이 문맥에서의 의미 순으로 정리합니다
  • 직접 질문 — 선택한 구절을 붙인 채로 자유 질문을 씁니다

자유 질문

아래 채팅창에 무엇이든 물어보면 됩니다. 질문을 보낼 때 현재 보고 있는 페이지 원문과 이전 페이지 끝부분이 자동으로 함께 전달되므로, "이 문단 논지가 뭐야" 같은 지시대명사 질문이 통합니다.

문맥은 페이지 단위입니다 현재 페이지에 없는 내용(예: 3장의 Methods를 1장에서 질문)은 답하지 못합니다. 해당 페이지로 스크롤한 뒤 물어보세요. 헤더의 p.12 표시가 지금 어느 페이지를 기준으로 답하는지 알려줍니다.

4. 그림·표 설명받기

헤더의 🖼 버튼을 누르면 커서가 십자로 바뀝니다. 그림이나 표를 드래그로 감싸면 그 영역이 잘려 채팅창에 썸네일로 붙습니다.

  • 질문을 비워 둔 채 보내면 "본문과 연결해 설명"이 기본 질문으로 나갑니다
  • "y축 단위가 뭐야", "이 패널 두 개 차이가 뭐야" 처럼 구체적으로 물으면 더 정확합니다
  • 취소하려면 🖼 를 다시 누르거나 썸네일의 ✕ 를 누릅니다
왜 그림만 보내지 않는가 잘린 이미지와 함께 그 페이지의 본문 전체가 전달됩니다. 그래서 캡션과 본문 서술을 근거로 그림을 읽습니다. 축 눈금처럼 화면에서 확실히 읽히지 않는 값은 지어내지 말고 "읽을 수 없다"고 답하도록 지시되어 있습니다.

5. 데이터가 어디로 가는가

대상어디로 가는가
PDF 파일어디로도 전송되지 않음. 브라우저 메모리에서만 처리
API 키브라우저 저장소에만 보관. Google 외 어디로도 전송되지 않음
질문·페이지 텍스트Google Gemini API로 전송
잘라낸 그림Google Gemini API로 전송
반드시 지켜주세요 무료 티어는 입력이 모델 개선에 사용될 수 있습니다. 미공개 원고, 심사 중인 논문, 대외비 문서는 넣지 마세요. 이런 자료를 다뤄야 한다면 유료 티어나 Vertex AI를 쓰거나, 아예 이 도구를 쓰지 마세요.
키 관리 키는 브라우저 개발자도구에서 확인할 수 있습니다. 공용 PC에서는 사용하지 말고, 부득이하게 썼다면 나갈 때 키 삭제를 누르세요. 키가 유출된 것 같으면 AI Studio에서 즉시 폐기하고 새로 발급하면 됩니다.

6. 문제 해결

화면 맨 위에 빨간 띠가 뜬다

스크립트 오류이거나 PDF 라이브러리 로딩 실패입니다. 띠에 적힌 문구를 확인하세요. cdnjs.cloudflare.com 관련이면 사내 방화벽이 원인일 수 있습니다.

버튼을 눌러도 아무 반응이 없다

브라우저에서 F12 → Console 탭의 빨간 줄을 확인하세요. 대개 스크립트가 초기화 도중 멈춘 경우입니다.

연결 테스트가 실패한다

진단 정보 패널을 펼치면 HTTP 상태 코드와 원문 오류가 기록되어 있습니다. 코드별 원인은 아래와 같습니다.

코드원인과 조치
400 / 403키 문제. AI Studio에서 키를 다시 확인하거나 새로 발급
404모델 ID가 존재하지 않음. 모델 불러오기로 목록에서 재선택
429무료 한도 초과. 잠시 후 재시도하거나 Flash-Lite 계열로 변경
fetch 실패네트워크 차단. 프록시·방화벽 확인

구절을 선택할 수 없다

텍스트 정보가 없는 스캔본입니다. 앱이 자동으로 경고를 띄웁니다. 이 경우 읽기는 되지만 선택·질문은 동작하지 않습니다. OCR 기능은 포함되어 있지 않습니다.

2단 조판 논문에서 답이 이상하다

PDF의 텍스트 추출 순서가 좌우 단을 넘나들며 섞이는 경우가 있습니다. 이럴 때는 해당 문단을 직접 드래그로 선택해 물어보면 정확해집니다.

7. 직접 배포하기

파일 하나짜리 정적 웹앱이라 배포가 단순합니다. 서버도 빌드도 필요 없습니다.

가장 간단한 방법 — 파일 그대로 공유

index.html 과 이 설명서를 함께 전달하면 됩니다. 받는 사람은 더블클릭만 하면 되고, 각자 자기 키를 넣어 씁니다.

웹으로 공개 — GitHub Pages

git init
git add index.html manual.html README.md LICENSE
git commit -m "Reading Companion"
git branch -M main
git remote add origin https://github.com/<계정>/reading-companion.git
git push -u origin main

GitHub 저장소 → Settings → Pages → Source를 main 브랜치로 지정하면 몇 분 뒤 https://<계정>.github.io/reading-companion/ 에서 열립니다. 무료입니다.

로컬 서버로 열기

파일로 직접 열었을 때 문제가 생기면 폴더에서 아래를 실행하고 http://localhost:8000/ 으로 접속하세요.

python -m http.server 8000
공개 배포 시 확인할 것 이 도구는 사용자가 각자 자기 API 키를 넣는 구조라, 배포자에게 비용이 발생하지 않고 로그인·결제·개인정보 수집도 없습니다. 다만 소속 기관의 이름이나 로고를 붙여 배포하면 기관 공식 산출물로 오해될 수 있으니, 개인 산출물임을 명시하거나 사전에 확인받는 편이 안전합니다.

8. 한계와 주의

  • 문맥은 페이지 단위 — 문서 전체를 아우르는 질문(전체 요약, 장 간 비교)에는 답하지 못합니다
  • 스캔본 불가 — OCR이 없어 이미지로만 된 PDF는 선택·질문이 되지 않습니다
  • 수식 처리 약함 — PDF의 수식은 텍스트 추출 시 깨지는 경우가 많습니다. 수식은 그림으로 잘라서 물어보세요
  • 무료 한도 — 분당·일일 요청 수 제한이 있습니다. 한도와 모델명은 수시로 바뀌므로 AI Studio에서 확인하세요
  • 답변을 검증하세요 — 언어모델은 틀릴 수 있습니다. 전문 용어나 수치는 원문과 대조하세요
