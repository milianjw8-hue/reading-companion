1. 이 도구는 무엇인가요

영어로 된 논문이나 원서 PDF를 화면에 띄워놓고, 모르는 문장을 마우스로 드래그하면 그 자리에서 번역과 설명을 해주는 도구입니다.

그림이나 표도 마찬가지입니다. 영역을 드래그로 감싸면 그 부분을 잘라서 질문할 수 있고, 이때 같은 페이지의 본문 내용이 함께 전달되기 때문에 캡션과 본문을 근거로 그림을 설명해 줍니다.

항목내용
설치없음. 웹사이트 접속 또는 파일 하나 실행
비용무료 (Google 무료 사용 한도 안에서)
준비물Google 계정, 인터넷, 웹브라우저(크롬 권장)
소요 시간처음 설정 5분, 이후 바로 사용
왜 무료인가요? 이 도구는 여러분의 Google 계정에 연결해서 동작합니다. Google이 개인에게 무료로 제공하는 사용 한도를 쓰기 때문에, 만든 사람도 쓰는 사람도 비용을 내지 않습니다. 신용카드 등록도 필요 없습니다.

2. 두 가지 방법 중 하나를 고르세요

사용 방법은 두 가지입니다. 어느 쪽이든 기능은 완전히 같습니다.

추천

방법 A — 인터넷에서 바로 쓰기

주소만 입력하면 끝입니다. 내려받을 것도, 압축을 풀 것도 없습니다. 처음 쓰시는 분은 이쪽으로 하세요.

선택

방법 B — 내 컴퓨터에 내려받아 쓰기

파일을 내 PC에 보관합니다. 인터넷이 불안정한 환경이거나, 나중에 직접 고쳐 쓰고 싶은 분에게 맞습니다.

스마트폰·태블릿은 반드시 방법 A 안드로이드와 iOS에서는 내려받은 HTML 파일을 직접 열면 보안 정책 때문에 질문 기능이 동작하지 않습니다. 모바일에서는 예외 없이 웹 주소로 접속해 주세요.
어느 쪽이든 인터넷은 필요합니다 PDF를 화면에 띄우는 것까지는 내 컴퓨터가 하지만, AI에게 질문하는 부분은 인터넷을 통합니다. 방법 B도 완전한 오프라인 사용은 불가능합니다.

3. [방법 A] 인터넷에서 바로 쓰기

1
브라우저 주소창에 아래 주소를 입력합니다
Reading Companion 실행 주소https://milianjw8-hue.github.io/reading-companion/
화면에 "영어 원서와 논문, 같이 읽어드릴게요"라는 문구가 나오면 성공입니다.
2
즐겨찾기에 추가해 두세요 PC는 Ctrl + D 로 즐겨찾기에 저장됩니다. 스마트폰은 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 아이콘이 생깁니다.
3
5장으로 넘어가 API 키를 등록합니다 아직 질문 기능은 동작하지 않습니다. 5장의 키 발급 절차를 진행하세요.
이 방법의 장점 설치가 아예 없습니다. 회사 PC, 집 PC, 노트북 어디서든 같은 주소로 접속하면 됩니다. 프로그램을 깔 수 없는 환경에서도 문제없이 쓸 수 있습니다.

아래 주소로 들어갑니다

index.html 파일을 더블클릭 압축을 푼 폴더 안에 여러 파일이 있습니다. 그중 index.html 을 더블클릭하면 브라우저가 열리면서 도구가 실행됩니다.
파일이 여러 개인데 어느 것인가요? index.html 이 본체입니다. manual.html 은 설명서, 나머지는 개발용 파일이라 무시하셔도 됩니다.
다른 프로그램으로 열리면 더블클릭했을 때 메모장이나 다른 프로그램이 뜬다면, 파일에서 오른쪽 클릭 후 "연결 프로그램"에서 Chrome을 선택하세요.

방법 A든 B든, 이 과정은 딱 한 번만 하면 됩니다. AI에게 질문할 수 있는 "출입증"을 받는 절차라고 생각하시면 됩니다.

1
Google AI Studio 접속
키 발급 페이지https://aistudio.google.com/apikey

API 키 만들기 클릭 화면에서 "API 키 만들기"(또는 Create API key) 버튼을 누르면 바로 만들어집니다.

"프로젝트를 선택하세요"라는 창이 뜨면 새 프로젝트 만들기를 누르시면 됩니다. 이름은 아무거나 괜찮습니다.

3
키를 복사합니다 AIza 로 시작하는 긴 문자열이 생성됩니다. 옆의 복사 아이콘을 누르세요.
4
Reading Companion 화면에 붙여넣기 Google AI Studio API 키 칸에 붙여넣습니다. Ctrl + V
5
사용 가능한 모델 불러오기 클릭 잠시 뒤 목록이 나타납니다. 이름에 "Flash"가 들어간 것을 아무거나 클릭하세요.
모델 이름을 직접 입력하지 마세요 무료로 쓸 수 있는 AI 모델의 이름은 수시로 바뀝니다. 반드시 불러오기로 나온 목록에서 고르셔야 오류가 나지 않습니다.
6
저장 → 연결 테스트 "저장"을 누른 뒤 "연결 테스트"를 누릅니다. 초록색으로 "연결 성공"이 나오면 모든 준비가 끝났습니다.
다음부터는 이 과정을 건너뜁니다 키는 브라우저에 저장됩니다. 다음에 열 때는 바로 PDF를 열어 쓰시면 됩니다. 단, 다른 컴퓨터에서는 다시 입력해야 합니다.

6. 실제로 사용해 보기

PDF 열기

PDF 선택 버튼을 눌러 읽으실 논문을 고릅니다. 수백 페이지짜리도 괜찮습니다. 화면에 보이는 부분만 그때그때 그리는 방식이라 느려지지 않습니다.

모르는 문장이 나왔을 때

마우스로 문장을 드래그해서 선택하면, 화면 아래쪽에 검은 막대가 나타납니다.

버튼기능
번역자연스러운 한국어로 옮겨줍니다
쉽게 설명앞뒤 문맥을 짚어가며 풀어서 설명합니다
단어·표현어려운 단어의 뜻과 이 문맥에서의 의미를 알려줍니다
직접 질문그 문장에 대해 원하는 것을 자유롭게 물어봅니다

그림이나 표가 이해되지 않을 때

화면 맨 위 오른쪽의 그림 아이콘을 누르면 마우스 커서가 십자 모양으로 바뀝니다. 이 상태에서 그림을 드래그로 감싸면, 그 부분이 잘려서 아래 채팅창에 작은 사진으로 붙습니다.

그대로 "질문" 버튼을 누르면 "본문과 연결해서 설명해 달라"는 요청이 자동으로 전달됩니다. 직접 질문을 써도 됩니다.

자유롭게 질문하기

화면 아래 채팅창에 무엇이든 물어보세요. 질문할 때 지금 보고 있는 페이지의 내용이 자동으로 함께 전달되므로, "이 문단이 무슨 말이야" 처럼 막연하게 물어도 알아듣습니다.

자주 쓰는 질문은 버튼으로도 준비되어 있습니다. 페이지 요약, 논지 정리, 용어 정리, 방법론 네 가지이며, 처음 보는 논문을 빠르게 훑을 때 유용합니다.

지금 몇 페이지를 기준으로 답하는지 확인하려면 화면 맨 위에 p.12 같은 표시가 있습니다. 이게 지금 AI가 보고 있는 페이지입니다. 다른 장의 내용을 물으려면 그 페이지로 스크롤한 뒤 질문하세요.

7. 연구자를 위한 활용 요령

수식은 드래그하지 말고 잘라내세요

PDF 안의 수식은 글자로 뽑아낼 때 대부분 깨집니다. 드래그로 선택하는 대신, 그림 아이콘으로 잘라서 이미지로 보내면 훨씬 정확하게 읽습니다. 이 방법 하나만 알아도 활용도가 크게 올라갑니다.

2단 조판 논문에서 답이 이상할 때

학술지 논문은 대부분 좌우 2단입니다. 이때 글자를 뽑아내는 순서가 좌우를 넘나들며 섞이는 경우가 있습니다. 답이 엉뚱하면 해당 문단만 직접 드래그해서 물어보세요. 바로 정확해집니다.

처음 보는 분야의 논문을 훑을 때

  1. 초록(Abstract) 페이지에서 "페이지 요약" 버튼
  2. Figure를 하나씩 잘라서 "본문과 연결해 설명" 요청
  3. Methods 페이지로 이동해 "방법론" 버튼

이 순서면 논문 한 편의 뼈대를 빠르게 잡을 수 있습니다.

전문 용어 확인

대기과학·기상 분야 용어는 국문 정식 용어와 영문을 함께 제시하도록 되어 있습니다. 예: 빙정핵(Ice Nucleating Particle, INP)

반드시 원문과 대조하세요 AI는 틀릴 수 있습니다. 특히 수치, 단위, 전문 용어는 반드시 원문을 확인하시기 바랍니다. 이 도구는 이해를 돕는 보조 수단이지, 원문 검토를 대신하지 않습니다.

8. 안 될 때 확인할 것

설정 화면 아래쪽의 진단 정보를 펼치면 오류 내용이 기록되어 있습니다. 아래 표에서 해당하는 것을 찾으세요.

증상원인과 해결
키가 유효하지 않습니다 키를 잘못 붙여넣었거나 앞뒤에 공백이 섞였습니다. AI Studio에서 다시 복사해 넣으세요.
모델 ID를 찾을 수 없습니다 모델 이름이 바뀌었습니다. 사용 가능한 모델 불러오기를 다시 눌러 목록에서 고르세요.
무료 한도를 초과했습니다 짧은 시간에 질문을 너무 많이 했습니다. 몇 분 기다렸다 다시 시도하세요.
구절 선택이 안 됨 스캔해서 만든 PDF입니다. 글자가 아니라 사진이라 선택할 수 없습니다. 이 경우 그림 잘라내기 기능은 사용 가능합니다.
화면 위에 빨간 띠 인터넷 연결이나 회사 방화벽 문제일 수 있습니다. 띠에 적힌 문구를 확인하세요.
버튼이 반응 없음 페이지를 새로고침(F5)해 보세요. 그래도 안 되면 브라우저를 Chrome으로 바꿔보세요.
연결에 실패했습니다
(모바일)		 내려받은 파일을 직접 열면 모바일에서는 차단됩니다. 3장의 웹 주소로 접속하세요.

9. 주의사항과 한계

미공개 자료는 넣지 마세요 무료로 제공되는 서비스는 입력한 내용이 AI 성능 개선에 활용될 수 있습니다. 다음 자료는 절대 넣지 마시기 바랍니다.
  • 아직 발표하지 않은 원고
  • 심사가 진행 중인 논문
  • 기관 대외비 문서

이미 공개된 논문을 읽는 용도로만 사용하시기 바랍니다.

내 자료는 어디로 가나요

대상전송 여부
PDF 파일 자체전송되지 않음. 내 컴퓨터 안에서만 처리
API 키내 브라우저에만 저장. 만든 사람도 볼 수 없음
질문과 페이지 글자Google AI로 전송
잘라낸 그림Google AI로 전송

기능상의 한계

  • 문서 전체 요약은 안 됩니다. 지금 보고 있는 페이지를 기준으로 답하기 때문에, "이 논문 전체를 요약해줘" 같은 질문은 처리하지 못합니다.
  • 스캔본은 글자 선택이 안 됩니다. 글자 인식(OCR) 기능은 들어 있지 않습니다.
  • 답변 검증이 필요합니다. 특히 수치와 전문 용어는 원문 확인이 필수입니다.
공용 PC에서 사용하셨다면 나가시기 전에 설정 화면에서 "키 삭제"를 눌러주세요. 키가 브라우저에 남아 다른 사람이 쓸 수 있습니다.
